# Configuración

Archivo › Configuración ajusta Lattis en este equipo. La configuración se aplica a todos los libros; se guarda en el archivo `config.json` de su perfil.

## Configuración impuesta {#reglages-imposes}

En una empresa, el administrador puede fijar algunos ajustes para todos los equipos. Un ajuste impuesto por la directiva de la organización se marca con un candado y no se puede cambiar; un ajuste fijado por otra configuración (variable de entorno, Registro…) lo indica debajo de la casilla.

## Servidor MCP {#serveur-mcp}

Archivo › Configuración › Servidor MCP (asistentes) permite que un asistente compatible con MCP (Claude Desktop, Claude Code…) lea y modifique el libro abierto. El servidor solo escucha en este equipo y exige un token, que se muestra en la misma ventana; cada cambio hecho por el asistente se deshace con `Ctrl+Z`.
