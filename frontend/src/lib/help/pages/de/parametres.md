# Einstellungen

Datei › Einstellungen konfiguriert Lattis auf diesem Computer. Die Einstellungen gelten für alle Arbeitsmappen; sie werden in der Datei `config.json` Ihres Profils gespeichert.

## Vorgegebene Einstellungen {#reglages-imposes}

In einem Unternehmen kann der Administrator manche Einstellungen für alle Computer festlegen. Eine durch die Richtlinie der Organisation vorgegebene Einstellung ist mit einem Schloss gekennzeichnet und lässt sich nicht ändern; eine durch eine andere Konfiguration (Umgebungsvariable, Registrierung…) festgelegte Einstellung weist unter dem Feld darauf hin.

## MCP-Server {#serveur-mcp}

Datei › Einstellungen › MCP-Server (Assistenten) erlaubt einem MCP-kompatiblen Assistenten (Claude Desktop, Claude Code…), die geöffnete Arbeitsmappe zu lesen und zu ändern. Der Server lauscht nur auf diesem Computer und verlangt ein Token, das im selben Fenster angezeigt wird; jede Änderung des Assistenten lässt sich mit `Strg+Z` rückgängig machen.
