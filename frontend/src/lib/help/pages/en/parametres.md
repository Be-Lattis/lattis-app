# Settings

File › Settings configures Lattis on this computer. The settings apply to all workbooks; they are stored in the `config.json` file of your profile.

## Enforced settings {#reglages-imposes}

In a company, the administrator can set some settings for all computers. A setting enforced by the organization's policy is marked with a padlock and can't be changed; a setting fixed by another configuration (environment variable, Registry…) says so under the box.

## MCP server {#serveur-mcp}

File › Settings › MCP server (assistants) lets an MCP-compatible assistant (Claude Desktop, Claude Code…) read and change the open workbook. The server only listens on this computer and requires a token, shown in the same window; each change made by the assistant is undone with `Ctrl+Z`.
