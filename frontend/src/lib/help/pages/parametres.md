# Paramètres

Fichier › Paramètres règle Lattis sur ce poste. Les réglages valent pour tous les classeurs ; ils sont rangés dans le fichier `config.json` de votre profil.

## Réglages imposés

Dans une entreprise, l'administrateur peut fixer certains réglages pour tout le parc. Un réglage imposé par la stratégie de l'organisation est marqué d'un cadenas et ne se change pas ; un réglage fixé par une autre configuration (variable d'environnement, Registre…) l'indique sous la case.

## Serveur MCP

Fichier › Serveur MCP (assistants) laisse un assistant compatible MCP (Claude Desktop, Claude Code…) lire et modifier le classeur ouvert. Le serveur n'écoute que sur cet ordinateur et exige un jeton, affiché dans la même fenêtre ; chaque modification de l'assistant s'annule avec `Ctrl+Z`.
