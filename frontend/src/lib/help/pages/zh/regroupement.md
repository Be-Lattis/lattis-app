# 相似选项卡与选择选项卡

将列相同的选项卡（每月、每年或每个城市一个）合并为一个表格，然后一次只显示一个值。

## 合并选项卡 {#regrouper-des-onglets}

许多工作簿都有**每月、每年或每个城市一个选项卡**，各选项卡的列相同。Lattis 会识别出它们：这些选项卡下方带有相同颜色的线条，系列之后有一个“⧉ 12 个相似的选项卡”标记（悬停时会突出显示相关选项卡）。在导入 .xlsx 文件后、打开时，或者当您第三次复制系列中的某个选项卡时（甚至在重命名副本之前），状态栏会提示一次：**合并…**、**稍后**（标记保留）或**不再建议**（保存在文件中：收到该文件的同事不会再被询问；右键单击标记也可找到）。

如果各选项卡之间至少有三分之二的列相同，这些选项卡就会被归为一组：年中添加的列在缺失的地方保持为空，重命名的列（“Amount $”）会与相邻的列（“Amount”）配对，窗格中始终会显示这一配对。系列中的选项卡名称可被识别：月份、年份、季度、周、日期、数字或字母序列（“Lot 1”、“Lot 2”；“Appendix A”、“Appendix B”）、市镇。

**数据 › 合并选项卡…**（或右键单击所选的多个选项卡）打开窗格：

1. **选项卡**：要合并的表格，可勾选，按选项卡顺序排列；
2. **类别列**：其名称（根据选项卡名称预填：Month、Year、Quarter、City、共同部分如“Lot”，否则为 Category，始终可以编辑）、类型，以及从每个选项卡获取的值（如有需要可更正）。该列位于表格的第一列，并带有包含其值的下拉列表；
3. **列**：匹配情况（✓ 存在，∅ 缺失，“Amount $ → Amount”已配对）和最终类型；变为文本的列会被标出；
4. **之后**：表格和新工作表的名称，以及旧选项卡的处理方式：**删除**（默认）或**保留并隐藏**，其表格重命名为 `January_old`；
5. **预览**：前几行和总行数，然后是引用旧选项卡的公式的摘要：“已迁移 14 个公式，2 个需要手动修正”，并附有列表（工作表、单元格、公式更改前 → 更改后）。

**合并**一步完成所有操作：`Ctrl+Z` 可恢复原来的选项卡。格式和错误的输入会跟随其所在的行。如果各选项卡之间没有重复的值，则保留**键**；否则合并后的表格没有键（值保持不变），Lattis 会举例说明：“没有键：F-001 同时出现在 January 和 February 中”。

引用旧表格的内容会被**迁移**到合并后的表格，并限定为旧选项卡对应的月份（年份、城市），在同一撤消步骤中完成，且值保持不变。如果“Summary”工作表中原来有 `SUM(January[Amount])`、`SUM(February[Amount])`……，迁移方式如下：

| 之前 | 之后 |
|---|---|
| `SUM(January[Amount])` | `SUMIFS(Sales[Amount], Sales[Month], "=January")` |
| 某列（或基于各列的计算，`SUM(January[Price]*January[Qty])`）的 `AVERAGE`、`MAX`、`MIN` | `AVERAGEIFS`、`MAXIFS`、`MINIFS`、`SUMIFS` |
| `COUNTA(January[Customer])` | `COUNTIFS(Sales[Customer], "<>", Sales[Month], "=January")` |
| `SUMIF`、`COUNTIF`、`SUMIFS`…… | 相同的函数，改为 `…IFS` 形式，并添加月份条件 |
| `ROWS(January)` | `COUNTIFS(Sales[Month], "=January")` |
| `COUNT`、`MEDIAN`、`MAX` 或 `AVERAGE` 中的多列、`UNIQUE(January[Customer])`…… | 筛选后的列：`FILTER(Sales[X], Sales[Month]="January")` |
| 基于 January 的数据透视表 | 基于 Sales 的相同数据透视表，并带有报表筛选 Month = January |
| 基于 January 的图表 | 基于 Sales 的相同图表，并带有筛选 Month = January（显示在其窗格中，可删除） |

其他表格的计算列和条件格式规则遵循相同的规则。以下情况**需要手动修正**，并会注明原因：具体某一行（`January[Amount][3]`）、`REFERENCE`、`VLOOKUP` 和 `EXISTS`（它们在指定名称的表格中查找键）、`SUBTOTAL`、整个表格（`FILTER(January, …)`）、来自旧表格的检查列表、查询；SQL 文本和 Lua 脚本不会被检测。在这种情况下，旧选项卡默认保留并隐藏，以便这些公式继续工作；否则会被删除。如果没有类别列，就无法再区分各选项卡：所有内容都需要手动修正。之后，按月汇总最好使用 Month × Amount 数据透视表，它会自动跟随新行。

在受保护的工作表上、已筛选的表格上（请先删除筛选）、由查询加载的表格或在服务器上共享的表格上，不能进行合并。

### 包含多个表格的选项卡 {#onglets-a-plusieurs-tableaux}

“2025”选项卡通常包含多个表格：每年都会变化的销售和支出表，以及从一个选项卡原样复制到下一个选项卡的价目表。此时 Lattis 会合并**整个工作表**：它将各选项卡中的表格逐个按族（列相同，如上所述）配对，并在窗格的**选项卡上的其他表格**下说明每个表格的处理方式：

- **合并**（会变化的表格：销售、每月备注）：生成带有类别列的合并表格，**跟随**选择选项卡；
- **只保留一份**（当各处数据相同时提供：价目表）：保留最后一个选项卡中的表格，不带类别列，所有年份共用。如果某份副本有所不同（“Prices 在 2024 年有变化”），窗格会将其标出，并建议改为合并，以免丢失任何内容；
- **留在原选项卡上**（适用于只出现在一个选项卡中的表格）：此时该选项卡会被保留并可见，以橙色选项卡显示以便查找，窗格中会给出说明。

合并后的工作表采用**最近一个选项卡的布局**：每个合并后的表格占据其原表格的位置，下方的内容按其增长的幅度下移，该选项卡中没有的表格依次放在下方。各选项卡的**自由单元格**会被迁移（可在窗格中取消勾选）：各处完全相同的标题、标签或合计只保留一份；表格下方的 `=SUM(Sales2025[Amount])` 变为 `=SUM(Sales[Amount])`，给出所显示年份的合计；在各选项卡之间不同的值（2024 年为“Target: 5,000”，2025 年为“6,000”，标题“January 2025”）会成为**按年单元格**：它显示所选年份的值，您在其中键入的内容只适用于该年份（选择“(所有年份)”时为空）。

类别也可以来自某个**单元格**，而不是选项卡名称（当选项卡名为 Sheet1、Sheet2……时，每个选项卡的 A1 中有标题“January 2025”）：窗格会建议最可靠的来源，可在**取自**中选择。在**同一工作表上以标题分隔堆叠**的相似表格（“Paris”、“Lyon”、“Marseille”）也以同样方式合并，类别取自这些标题。如果每个选项卡都有一个 **Date** 列，且其值都在该选项卡的月份内，则 Month 列就没有必要了：“不添加列”复选框默认处于勾选状态（按日期筛选就足够了）；如果仍要添加该列，请取消勾选。

**跟随年份**：在带有选择选项卡的工作表上，跟随年份的表格会在其边框角上显示一个小**标记**，标明所显示的年份；没有标记的表格对所有年份都相同。右键单击表格 › 表格 › **跟随年份**（或单击标记）可勾选或取消勾选：勾选时会在最后添加 Year 列，并填入所显示的年份（选择某一年份时隐藏）；取消勾选时，如果该列只有一个年份则将其删除，否则保留该列（不会丢失任何内容），表格显示其所有行。在设置为某一年份的工作表上设置格式的表格（插入 › 表格）会自动跟随该年份；状态栏会给出提示。`Ctrl+Z` 可撤消。脚本：`tables.follow_choice("Prices", false)`。

## 选择选项卡（一次一年、一个月、一个城市） {#onglet-a-choix-une-annee-un-mois-une-ville-a-la-fois}

与其每年一个选项卡，不如只保留一个带有 Year 列的表格，并将其工作表设置为**选择选项卡**：右键单击选项卡 › **选择依据** › 该列（Lattis 会建议不同值较少的列）。选项卡变为“Sales · Year ▾”；其小箭头（或在选项卡上按 `Alt+↓`）会展开值列表：

- **某个值**（2025）：工作表上所有具有该名称列的表格只显示该值对应的行，而各处相同的 Year 列会被隐藏。没有该列的表格（价目表）不变。工作表上的数据透视表只统计该年份，就像强制应用了报表筛选一样；`SUBTOTAL`、图表和查找也会像跟随筛选一样跟随它；
- **(所有年份)**：不再隐藏任何内容，该列重新出现；
- **新年份…**会建议下一个值（2025 之后为 2026，November 之后为 December，Lot 3 之后为 Lot 4），将其添加到该列的下拉列表中并显示它：工作表看起来是空的，可以开始填写，就像一个新选项卡一样。`Ctrl+Z` 可撤消。

**从列开始**：对于已填好数据的表格，右键单击 Year 列标题（或其 ▾ 菜单） › **按此列筛选选项卡**可达到同样的效果，而无需通过选项卡或合并选项卡。选项卡开始时显示所有值：使用其 ▾ 箭头选择年份。对于计算列、空列或不同值超过 100 个的列，该菜单项显示为灰色，并有工具提示说明原因；对于已用作选择依据的列，该菜单项变为**停止筛选选项卡**。`Ctrl+Z` 可撤消。

**按公式**：如果要选择的值不是某一列，而是根据每行的各列计算得出，请右键单击选项卡 › **选择依据** › **公式…**：`=YEAR([Date])` 无需 Year 列即可按年份分选项卡，`=TEXT([Date],"mmmm")` 按月份，`=IF([Amount]>1000,"Large","Small")` 按区间。键入时，对话框会提示函数和列，推测类别名称（Year、Month……，可编辑），并显示公式的前几个值以及将跟随它的工作表上的表格：即具有公式所引用的所有列的表格（其他表格不变；右键 › 表格 › **跟随**可将其移除或重新加入）。选项卡的列表按自然顺序对值排序（2024 在 2025 之前，January 在 February 之前）。由于没有需要填写的列，因此没有“新年份…”：在表格下方键入的行不会自动获得任何值，但在您键入时它会保持显示，直到选项卡的值下次更改，此时它会归入其公式给出的值。`=SHEETCHOICE()` 返回所选的值（对于 `=YEAR(…)` 为数字）；工作表上基于具有该公式各列的表格所建的数据透视表只统计所选的值。重命名被引用的列时，公式会随之更新。脚本：`sheets.choose_by_formula("Sales", "=YEAR([Date])", "Year")`。

**从数据透视表开始**：在数据透视表窗格中右键单击行、列或筛选中的字段（或网格中该字段的 ▾） › **按此字段筛选选项卡**。选择选项卡设置在数据透视表所在的工作表上，依据其源表格中的列：数据透视表只统计所选的值，工作表上基于具有该列的表格所建的其他数据透视表以及具有该列的表格也是如此。如果源表格位于另一个工作表上，则不会被筛选；其值用于填充选项卡的列表。对于基于由查询加载的表格所建的数据透视表，此功能同样适用。

在表格下方或在其他年份各行的灰色条带中键入的行会自动获得所显示的年份；粘贴或插入的行也是如此。选择并不是筛选：“清除筛选”不会影响它，而您通过 ▾ 设置的筛选会叠加在其上。`Ctrl+Alt+PgDn` 和 `Ctrl+Alt+PgUp` 转到下一个或上一个年份；状态栏会提示“Year: 2025（选项卡选择）”。

**工作表上**的自由公式看到的是经过筛选的表格：放在表格下方的 `=SUM(Sales[Amount])` 给出所显示年份的合计，就像原来的“2025”选项卡一样。其他工作表上的公式、SQL 选项卡和脚本看到的是所有行。`=SHEETCHOICE()` 返回所选的值，可用于跟随选项卡的汇总：`=SUMIFS(Sales[Amount], Sales[Year], SHEETCHOICE())`。

更改年份属于导航，就像切换选项卡一样：它不是一个撤消步骤，但最后选择的值会保存在文件中，并在打开时恢复（如果该值已没有任何行，选项卡会显示最后一个值，除非刚刚使用了“新年份…”）。重命名该列会重命名类别：选项卡随之更新。右键 › 选择依据 › “停止按…选择”会删除选择（可撤消）。在共享工作簿中，选择只保留在您的计算机上：不会发送给其他人。

脚本：`sheets.choice()`、`sheets.set_choice("Sales", 2025)`、`sheets.choose_by("Sales", "Year")`（对于放在其他位置的数据透视表所在的工作表：`sheets.choose_by{table = "Sales", column = "Year", sheet = "Summary"}`）、`sheets.new_choice("Sales", 2026)`（请参阅 [Lua](lua)）。
