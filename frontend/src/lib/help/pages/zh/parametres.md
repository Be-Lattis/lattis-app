# 设置

文件 › 设置用于配置本机上的 Lattis。设置对所有工作簿生效，保存在您个人配置文件夹中的 `config.json` 文件里。

## 强制设置 {#reglages-imposes}

在企业中，管理员可以为所有计算机统一指定某些设置。由组织策略强制的设置带有锁形图标，无法更改；由其他配置（环境变量、注册表等）指定的设置会在选项下方注明。

## MCP 服务器 {#serveur-mcp}

文件 › 设置 › MCP 服务器（助手）允许兼容 MCP 的助手（Claude Desktop、Claude Code 等）读取和修改当前打开的工作簿。服务器只在本机上监听，并要求提供令牌（显示在同一窗口中）；助手所做的每项修改都可以用 `Ctrl+Z` 撤消。
