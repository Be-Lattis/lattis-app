# 导入数据和连接

数据 › 获取数据可将数据导入表格，方式类似 Power Query：每次转换都成为一个可重放的步骤，表格可按需刷新。

## 数据源 {#sources}

| 数据源 | 说明 |
| --- | --- |
| 文本或 CSV 文件 | 可选择分隔符 |
| .xlsx 文件 | 可选择一个工作表 |
| JSON 文件、Parquet 文件 | |
| SQLite 数据库（文件） | 一个表或一个查询 |
| PostgreSQL、MySQL / MariaDB、SQL Server | 通过连接（见下文） |
| Web（JSON API） | 返回 JSON 的地址 |
| 工作簿中的表格、其他查询、工作簿 SQL 查询 | 用于转换已有的数据 |

## 查询编辑器 {#l-editeur-de-requete}

编辑器显示数据预览和**应用的步骤**列表。其功能区中的命令会添加一个步骤：

- **列**：选择、删除、重命名、更改类型；
- **行**：筛选、排序（如有需要，可使用自定义顺序：列出的值按此顺序排在最前）、删除重复项、保留前几行；
- **转换**：拆分、替换值、格式（TRIM、UPPERCASE 等）、自定义列、索引列、分组依据、透视、逆透视；
- **组合**：合并（联接）或追加另一个查询或表格的行。

单击预览中的某一列即可选中该列；`Ctrl+Z` 删除最后一个步骤。结果可加载到表格中，也可仅保留为连接。

## 查询和连接 {#requetes-et-connexions}

**查询和连接**窗格（数据 › 查询和连接）列出工作簿中的查询：编辑、刷新、删除。在由查询加载的表格中按 `F5` 可重新运行该查询；`Ctrl+F5` 或数据 › 全部刷新会重新运行所有查询，然后重新计算公式。在表格标题右侧键入名称可添加一个输入列，刷新时会保留（请参阅[在链接结果旁边输入](sql)）。

## 收到的工作簿：数据源许可 {#classeur-recu-accord-des-sources}

查询保存在工作簿中。为避免收到的工作簿在刷新时连接未知服务器或复制您计算机上的文件，查询首次要读取文件或连接主机（Web API、数据库服务器）时，Lattis 会征求您的同意。同意在本次会话中有效；勾选“记住”后，则对本机上的此工作簿有效。在编辑器中编写的查询的数据源，以及您在其中选择的文件，会自动获得许可。已许可的主机可在脚本选项卡 › 网络访问中查看。

## 数据库连接 {#connexions-aux-bases}

**连接**描述一个服务器（PostgreSQL、MySQL / MariaDB、SQL Server 或 Web API）：主机、端口、数据库、用户。连接保存在工作簿中，可供多个查询使用。在窗格中通过其 **⋯** 菜单可以重命名连接：使用该连接的查询会随之采用新名称（`Ctrl+Z` 可全部撤消）。

密码从不保存在工作簿中：它们保存在系统钥匙串中，Lattis 会在首次刷新时询问密码。在该窗格中也可以清除已保存的密码。

在企业中，连接可以由计算机的配置提供；无需输入任何内容即可显示。
