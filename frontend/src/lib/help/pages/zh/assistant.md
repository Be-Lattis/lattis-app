# AI 助手

**助手 ✦** 帮助您构建分析：它读取表格的结构，提出分析思路，并可以添加计算列、键、数据透视表和图表，以及排序或设置格式。它在网格右侧的窗格中打开，就像 Excel 中的 Copilot 一样，切换工作表时仍保持打开。

## 启用助手 {#activer-l-assistant}

助手默认处于关闭状态：在文件 › 设置 › 功能中勾选**AI 助手**。随后功能区右上角会出现**助手 ✦**按钮（`Alt+I`），用于打开其窗格；取消勾选后，按钮、快捷键和窗格都不再出现。在企业中，组织策略可以关闭或强制启用助手。

## 连接 {#se-connecter}

窗格标题栏中的**连接**按钮提供两种方式。只要尚未连接，该面板就会自动打开。

### API 密钥（推荐） {#cle-d-api-recommande}

1. 选择提供商（Anthropic、Mistral、OpenAI、Gemini、Mammouth 等）和模型，然后单击**打开控制台**：即提供商用于创建密钥的页面。
2. 复制密钥，然后单击**粘贴**（或在字段中按 `Ctrl+V`）。
3. **验证并保存**：Lattis 会先向提供商测试该密钥，然后再保存。密钥被拒绝或账户没有额度时，面板中会显示明确的消息。

密钥保存在系统钥匙串中，从不保存在工作簿中。**忘记密钥**可将其删除。

> 在 Anthropic，密钥只有在有额度时才能使用：请在控制台的**账单**页面（platform.claude.com）中充值。**Claude Max** 和 **Team** 订阅每月提供 API 额度（根据套餐不同为 100 至 500 美元）：在 claude.ai › 设置 › 账单中关联控制台的组织即可领取。Pro 和 Enterprise 订阅不提供 API 额度。

### 桌面应用（Claude Pro、Max、Team 订阅） {#application-de-bureau-abonnement-claude-pro-max-team}

Claude 订阅不能直接在其他应用程序中使用，但 **Claude Desktop** 和 **Claude Code** 可以通过 Lattis 的 MCP 服务器操作 Lattis。连接面板中的“桌面应用”选项卡（应用：Claude）可一键完成配置；然后重新启动 Claude Desktop。

之后您就在 Claude 的应用中与 Claude 对话。助手窗格会显示**来自 Claude**：实时显示 Claude 在工作簿中所做的操作，每组操作都有**撤消这些修改**按钮。**修改前询问**选项会让您在 Lattis 中确认每次写入，包括以其他名称保存、导出和导入。**发送给助手的数据**设置同样适用于 Claude（见下文）。

### 组织网关 {#passerelle-de-l-organisation}

如果企业提供了自己的网关，窗格会显示“已通过您所在组织的网关连接”：无需输入密钥，也无需选择提供商。

### 本地模型 {#modele-local}

**本地模型**提供商使用安装在本机上的模型（Ollama、LM Studio 等）：任何数据都不会离开计算机，也不需要密钥。其地址可在连接面板中或在文件 › 设置 › AI 助手中设置。此功能为实验性功能：小模型调用 Lattis 工具的能力较弱。

## 对话 {#converser}

键入您的请求，然后按 `Enter`（`Shift+Enter` 换行）。每条消息都会附带您正在查看的内容：活动工作表、光标所在的表格以及所选内容，这些信息显示在输入框上方（“上下文：Orders，所选内容 Amount[3:10]”）。因此，“分析这个表格”或“解释这一列”针对的就是所选内容。

- 助手的步骤（读取表格、添加列等）会归入一行 **N 个步骤**，回答期间展开，回答结束后折叠；单击可再次展开。带下划线的步骤名称可跳转到相关的工作表或表格。
- 失败后又被助手修正的步骤显示为灰色；只有未得到处理的错误才显示为红色。
- `Esc` 停止当前回答。如果在模型回答之前停止，或在此时失败（网络、配额），该回答会消失，您的消息会回到输入框中：模型并未收到它。
- 在空的输入框中按上方向键可调出上一条消息；回答下方的复制按钮可将回答复制到剪贴板。
- 因错误（提供商过载、连接中断）而中断的回答下方有**重试**按钮，可从中断处继续，而无需重新发送您的消息：已经做过的修改不会重做，整个回答仍然可以一次撤消。当错误要求等待时（“请在 30 秒后重试”），按钮会倒计时。
- 很长的回答会在 100 个步骤后停止：**继续**可用同样的方式接着回答。
- 关于数据的问题（“哪个城市的营业额最高？”）会在回答下方得到一个**结果**：助手编写查询，Lattis 在本机上运行该查询，并最多向您显示 50 行。在“仅结构”模式下，结果只供您查看：助手既看不到其中的值，也看不到其行数。
- 助手用您的语言回答，并按网格中的写法书写公式（中文界面为 `SUM(a, b)` 和 `1.2`）。写入公式后，它会检查错误（#NAME?、#REF!…）并在回答前加以修正。
- 回答中的链接会显示其域名（“查看报告 (example.com)”）；单击会显示完整地址，并在浏览器中打开之前请求确认。
- **新建**（窗格标题栏）开始新的对话；之前的对话保留在对话列表（☰）中，可以从中继续或删除（需确认）。
- 对话变长时，助手会总结前面的内容以便继续：**会话已压缩**标记会显示总结的位置。窗格中仍然显示所有内容；只是模型此后基于总结进行工作。

## 修复识别有误的表格 {#reparer-des-tableaux-mal-reconnus}

**修复此工作表中的表格**建议会让助手重新读取工作表的布局：表格的位置、表格第一行和最后一行中单元格的性质（文本、数字、日期、公式、空），加粗或合并的自由单元格，以及看起来像标题或总计的行。它不读取其中的值，在“仅结构”模式下也是如此。然后，它会使用保留表格、表格的键以及引用该表格的公式的命令进行修正：被误当作标题行的标题文字、遗留在数据中的标题行、移出表格的总计行、占两行的标题、需要拆分的列。

助手在工作簿中读取的内容（名称、单元格文本）都作为数据而不是指令提供给它：如果某个单元格“要求”它删除一列，它不应照做，并会指出这一点。只有在您要求时，它才会删除列、图表、数据透视表或重复项。

**在工作簿中保留对话**设置（文件 › 设置 › AI 助手）会将对话与工作簿一起保存；否则，关闭工作簿或打开另一个工作簿时，对话会被清除。保留的对话随文件一起传递，包括显示的结果和助手读取的行，并且只有在工作簿也被修改时才会保存。如果工作簿在回答之外发生了变化（导入、`Ctrl+Z`、稍后继续对话），助手会在下一条消息中收到其最新结构。

## 撤消 {#annuler}

助手在一次回答中所做的所有修改构成一个步骤：回答以其摘要（“3 处修改”）和**撤消此回答**按钮结束。在网格中按 `Ctrl+Z` 效果相同。该按钮只对最后一次回答有效，且之后没有进行过其他修改；否则请使用 `Ctrl+Z`。

## 发送的数据 {#donnees-transmises}

**发送给助手的数据**设置（文件 › 设置 › AI 助手，窗格底部也会显示）用于选择助手可以读取的内容：

| 设置 | 提供商收到的内容 |
| --- | --- |
| 仅结构（默认） | 工作表、表格和列的名称，类型，行数和非重复值的个数，公式，表格和单元格在工作表上的位置（不含其内容，但包含其性质以及“标题”或“总计”提示）；不包括所显示查询的结果，也不包括替换所涉及的单元格数；查询步骤和连接参数，但不含密码以及 HTTP 标头和筛选条件的值。数据透视表中承载某字段各个值的列会被概括（“字段“Customer”的 3 个值列”） |
| 结构和示例行 | 同上，另外每次读取时附带几行数据：最多 20 行，每个值最多 200 个字符 |
| 整个工作簿 | 助手选择读取的所有内容，不受限制 |

提供商还会收到您的消息和上下文（工作表、表格、所选内容）。使用本地模型时，任何数据都不会离开本机。

该设置同样通过 MCP 服务器适用于 **Claude Desktop** 和 **Claude Code**：如果未选择“整个工作簿”，读取值的工具（表格行、SQL、单元格、脚本、导出）不会提供给它们，或以同样的方式受到限制。更改设置后，请重新启动 Claude，使其看到新的工具列表。Claude Code 还会读取您磁盘上的文件：已保存的工作簿它仍可以直接读取。

## 费用 {#cout}

使用 API 密钥时，提供商会根据读取和写入的令牌数对每次回答计费。使用 Anthropic 密钥时，窗格底部会根据公开价格显示对话费用的估算（“本次对话 ≈ 0.12 美元”）；以提供商的账单为准。对于其他提供商或通过网关连接时不显示估算，因为其价格不同。较长的步骤序列费用更高：较轻量的模型（Sonnet 而不是 Opus）通常就足够了。

## 限制 {#limites}

- 助手可能会出错：请检查它的建议，并撤消不合适的回答。
- 在“仅结构”模式下，它看不到值：无法判断单元格的内容。在“结构和示例行”模式下，它只能看到一部分值。
- 很长的对话会被总结（“会话已压缩”）：此时助手可能会忘记最初交流中的某个细节。对于新的主题，最好开始新的对话。
- 使用 Claude Desktop 或 Claude Code 时，对话保留在 Claude 中；Lattis 只能看到操作。
