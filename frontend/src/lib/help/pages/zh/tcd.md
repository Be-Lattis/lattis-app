# 数据透视表

数据透视表用于汇总表格：按客户、按月份、按地区等计算合计。Lattis 使用 SQL（`GROUP BY`）计算数据透视表，即使有一百万行也依然快速。

## 创建数据透视表 {#creer-un-tableau-croise}

1. 单击源表格中的任意位置。
2. 插入 › 数据透视表。状态栏显示“单击要放置数据透视表的单元格（Esc：取消）”。
3. 单击数据透视表左上角要放置的单元格。等待期间不会锁定任何操作：您可以滚动工作表、用键盘移动、切换选项卡（此时数据透视表将放置在另一个工作表上）或使用功能区。按 `Esc`（或状态栏中的**取消**）可放弃。
4. 数据透视表放置完成，右侧打开**数据透视表字段**窗格。

若要像 Excel 默认的那样将其单独放在新工作表上，请单击状态栏中的**新工作表**，而不是选择单元格。

## 移动数据透视表 {#deplacer-un-tableau-croise}

- 在数据透视表上**右键 › 移动**，然后单击其左上角（包括报表筛选）要放置的单元格，可以在同一工作表或另一个工作表上；按 `Esc` 取消。
- 也可以像移动表格一样拖动所选内容的边框：在数据透视表中选择的内容（只需一个单元格）会带动整个数据透视表；按住 `Ctrl` 则为复制。
- 也可以剪切整个数据透视表（`Ctrl+X`），然后粘贴（`Ctrl+V`）到其他位置。

数据透视表会精确放置在所选单元格处。它覆盖或接触到的表格和其他数据透视表会向右让开，彼此之间保留一个空列，并依次推开它们碰到的对象；因此，在另一个表格中单击会把它推到数据透视表的右侧。浮动在网格之上的图表和按钮不会移动。每次放置或移动都可以一次撤消（`Ctrl+Z`）。

数据透视表的单元格不能逐个输入：双击单元格可更改其字段。

## 字段窗格 {#le-volet-des-champs}

顶部的列表显示源表格的列，并带有表示其类型的图标；搜索框可筛选列表。勾选字段可将其添加，或将其拖到四个区域之一：

| 区域 | 作用 |
| --- | --- |
| 筛选 | 报表筛选，位于数据透视表上方 |
| 列 | 字段的每个值对应数据透视表的一列 |
| 行 | 字段的每个值对应数据透视表的一行（多个字段会嵌套） |
| 值 | 计算得出的数字 |

每个字段标签都有 ▾ 菜单：移动、删除、筛选，对于值字段还可设置汇总方式和值显示方式。使用键盘时：`Tab` 在各项之间移动，`Enter` 打开字段标签的菜单，`Del` 将其删除，`Alt+Up` / `Alt+Down` 移动它。

计算列暂时还不能用作字段。

### 计算字段（按公式分组） {#champ-calcule-regrouper-par-une-formule}

字段列表下方的**计算字段…**用于添加一个字段，其值由基于源表格各列的公式为每一行计算得出，列名写在方括号中：`=YEAR([Date])` 按年份分组，`=TEXT([Date],"mmmm")` 按月份分组，`=LEFT([Code],2)` 按代码的前两个字符分组，`=IF([Amount]>1000,"Large","Small")` 按区间分组。键入时，对话框会提示函数和列，并显示公式得出的前几个值（或其错误）。该字段以 ƒ 图标加入列表，可以像列一样放置：放在行或列中时，按其结果对行分组；放在筛选中时，用于筛选；放在值中时，进行汇总。通过其在列表中的 ▾ 菜单可以编辑或删除它（删除后它会离开各区域）。数据透视表每次更新时都会重新计算该字段；重命名源表格中的列时，公式会随之更新。`Ctrl+Z` 可撤消。脚本：在 `pivots.create` 或 `pivots.set` 的配置中使用 `calc = {{name = "Year", text = "=YEAR([Date])"}}`。

## 值汇总和显示方式 {#synthese-et-affichage-des-valeurs}

汇总方式：求和、计数、非重复计数、平均值、最小值、最大值。数字列默认求和，其他列默认计数。值也可以显示为百分比：占总计的百分比、占列汇总的百分比或占行汇总的百分比。可以为每个值字段选择数字格式（货币、百分比、小数位数）。

## 对标签排序和筛选 {#trier-et-filtrer-les-etiquettes}

行标签的 ▾（或窗格中行和列区域内字段标签的 ▾ 菜单）可对字段排序：从 A 到 Z、从 Z 到 A、按源数据顺序，或通过**自定义排序…**，按您需要的顺序或依据某个列表（星期、月份、工作簿中的列表）排列字段的值，与[表格列](prise-en-main)相同。标签的 ▾ 还可以通过勾选来筛选其值。未选择排序时，标签按源表格中的顺序排列。所选顺序保存在数据透视表中：数据变化时，列表中新出现的值会占据其应有的位置，其余的值按升序排在后面。与 Excel 相同，无论如何排序，字段中的空单元格始终作为最后一项：位于总计之前的最后一行（或列），并在 ▾ 菜单列表末尾显示为“(空白)”。

## 更新 {#mise-a-jour}

数据透视表会在短暂延迟后跟随窗格中的更改，作为一个撤消步骤。它也会跟随源表格的数据变化。在数据透视表中单击即可重新打开窗格。

## 在右侧添加列 {#ajouter-des-colonnes-a-droite}

在数据透视表标题紧右侧的单元格中键入名称：数据透视表就会在其边框内增加一个**输入列**，标题为绿色（数据透视表的其余部分保持计算数据的蓝色）。其单元格可以像普通单元格一样编辑：

- **值**逐行输入（备注、目标、评论）。值跟随其行标签：当数据透视表发生变化时（源表格数据、排序、筛选、字段），值会保持在同一标签旁边。消失的标签会将其值**暂存**；标签重新出现时，值也会恢复。字段窗格会显示暂存的行数，**清除暂存的值**可将其删除（按 Ctrl+Z 撤消）。删除行区域中的所有字段会暂存所有值；字段恢复时，值也会恢复。更换行区域中的字段也是如此：值按字段和标签分别保存。
- **公式**（以 = 开头）作用于整列，就像计算列一样：`=[Count]*2` 读取该行在数据透视表“Count”列（或另一个输入列）中的值，`=[Count]/SUM(TCD1[Count])` 与整列进行比较（仅明细行），而 `=B3` 或 `=A20*[Count]` 之类的地址则读取工作表中的单元格。公式也会在总计行上计算。在公式列中键入的值会被拒绝；清除其中一个单元格会清除公式（之前输入的值会恢复）。
- **总计**行和小计行不接受值。
- 重命名：重新键入标题。删除该列：清除其标题（对整列按 Del，或清除标题），其值会随之删除（按 Ctrl+Z 撤消）。

当数据透视表变宽时（列区域中多了一个值或字段），输入列始终保持在数据透视表的右边缘，并像数据透视表本身一样推开旁边的内容。输入列随数据透视表一起移动；复制数据透视表时也会复制其值。其他位置的公式可以通过地址（`=E5`）读取输入列，数据透视表的 SQL 视图也包含输入列。

## 在其他位置使用数据透视表 {#utiliser-un-tableau-croise-ailleurs}

数据透视表有一个名称（显示在窗格顶部）：可以在 [SQL 选项卡](sql)中像表一样查询它，也可以作为[图表](graphiques)的数据源。[GROUPBY](fonction:GROUPBY) 函数可以直接在公式中实现简单的分组。

**在公式中**，数据透视表可以像命名表一样按名称读取（名称显示在其边框左上角的蓝色标签上）：`=SUM(TCD1[计数])` 读取整列（仅明细行，不含分组、小计和总计），`=TCD1[NID][2]` 读取第二个明细行，输入列也以同样方式读取（`TCD1[test]`）。输入公式时，单击数据透视表会写入这些引用而不是单元格地址：在数据透视表输入列中输入的公式所在行写入 `[计数]`，其他位置写入 `TCD1[计数][2]`，在标题或总计行上写入 `TCD1[计数]`。在输入列中，`[计数]`（或 `[@计数]`）也会在分组、小计和总计行上按其自身的值计算；比该行更细的行字段在这些行中为空。
