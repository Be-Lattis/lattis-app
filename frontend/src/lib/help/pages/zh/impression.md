# 页面布局和打印

文件 › 打印 / PDF（`Ctrl+P`）打印活动工作表。若要生成 PDF，请在打印窗口中选择“Microsoft Print to PDF”打印机（或“另存为 PDF”）。打印内容在功能区**视图**选项卡的“页面设置”组（`Alt+W`）中设置。这些设置属于工作表：随工作簿保存，可用 `Ctrl+Z` 撤消，并随工作表的副本一起复制。

## 页面设置组（视图选项卡） {#groupe-mise-en-page-onglet-affichage}

| 命令 | 作用 |
| --- | --- |
| 页边距 | 常规、宽或窄；“自定义页边距…”打开“页面设置”对话框 |
| 纸张方向 | 纵向或横向 |
| 纸张大小 | 纸张规格：A4、A3、A5、B5、Letter、Legal、Tabloid、Executive |
| 打印区域 | “设置打印区域”：只打印所选内容。“取消打印区域”：重新打印整个已用区域 |
| 分隔符 | “插入分页符”：从活动单元格的上方和左侧开始新的一页（在第 1 行时只在左侧）。“删除分页符”删除这些分页符。“重设所有分页符”删除所有手动分页符 |
| 打印标题 | 在每页顶端重复的行和在左侧重复的列 |

插入或删除行和列时，打印区域、标题和分页符会随之移动。

## 缩放 {#mise-a-l-echelle}

**宽度**和**高度**将工作表调整为指定页数：Lattis 会缩小工作表（最小到 10%）以使其容纳得下。宽度为“1 页”、高度为“自动”时，所有列都会放在一页的宽度内。调整为指定页数时，手动分页符会被忽略，与 Excel 相同。**缩放比例**按固定百分比打印，并取消调整为指定页数。

## 工作表选项 {#options-de-la-feuille}

“查看网格线”和“查看标题”只影响屏幕显示。“打印网格线”会为所有单元格绘制网格线。“打印标题”会添加列字母和行号。不打印网格线时，只有表格中的单元格带有边框。

## “页面设置”对话框 {#la-boite-mise-en-page}

每个组右下角的小按钮可打开**页面设置**对话框。它有四个选项卡：

- **页面**：纸张方向、缩放比例或调整为指定页数、纸张大小、起始页码。
- **页边距**：上、下、左、右、页眉和页脚（单位为厘米），以及在页面上水平居中和垂直居中。
- **页眉/页脚**：预设格式（“第 1 页，共 ? 页”、工作表名称、文件名等），或三个自由区域（左、中、右）。按钮用于插入代码：`&[Page]`、`&[Pages]`、`&[Date]`、`&[Heure]`（时间）、`&[Fichier]`（文件）、`&[Chemin]`（路径）、`&[Onglet]`（选项卡）。这些代码在所有语言中都相同。若要输入单个 & 符号，请写 `&&`。
- **工作表**：打印区域（`$A$1:$F$40`）、顶端重复的行（`$1:$1`）和左侧重复的列（`$A:$A`）。**所选内容**按钮会采用工作表中的当前选择。网格线、标题、单色打印以及打印顺序（先列后行或先行后列）也在此设置。

**打印…**应用这些设置后进行打印。

## 网格中的分页符 {#sauts-de-page-dans-la-grille}

打印或更改页面布局后，虚线会显示页面的分隔位置。手动分页符以更粗的短划线显示，打印区域带有边框。视图 › **分页符**用于显示或隐藏它们。

## 打印的内容 {#ce-qui-s-imprime}

按网格中显示的样子打印值，并保留列宽和行高。表格标题以粗体打印，合并的单元格保持合并。隐藏的行和列不会打印。Lattis 自行分页。因此，每个打印页的大小都与所选纸张相同，并带有其页边距、页眉和页脚。

限制：

- 单元格格式（颜色、字体、边框）和图表暂时还不能打印。
- 超过 5,000 行时，后面的部分不会打印：请筛选工作表或导出工作簿。
- 在打印窗口中，请将页边距保持为“默认”，缩放比例保持为 100%。否则 Lattis 准备好的页面会发生偏移。
- 如果窗口提供“页眉和页脚”选项，请不要勾选：它会添加浏览器自身的页眉和页脚（日期、地址）。

## Excel 和 OpenDocument {#excel-et-opendocument}

工作簿导出为 `.xlsx` 或 `.ods` 时，页面布局也一并导出：纸张、方向、页边距、缩放比例或调整为指定页数、打印区域、标题、分页符、网格线、标题、居中方式、页眉和页脚。导入 `.xlsx` 时，Lattis 会沿用每个工作表的页面布局。

## 脚本 {#scripts}

`sheets.page_setup()` 读取工作表的页面布局，`sheets.set_page_setup({...})` 更改页面布局（请参阅 [Lua 参考](lua:sheets.set_page_setup)）。
