# 按钮和控件

与 Excel 的表单控件一样，控件可以自由放置在工作表上（或[文档](onglets)中）：插入 › 按钮，或插入 › 字段。

## 控件类型 {#types-de-controles}

| 控件 | 作用 |
| --- | --- |
| 按钮 | 单击即运行所链接的操作 |
| 复选框 | 在链接的单元格中写入 TRUE 或 FALSE |
| 下拉列表 | 在链接的单元格中写入所选项 |
| 输入框 | 离开输入框或按 `Enter` 时，将文本写入链接的单元格 |
| 文本框 | 与输入框相同，但可多行输入（按 `Ctrl+Enter` 确认） |
| 文件选择器 | 在链接的单元格中写入所选文件的路径 |

## 控件窗格 {#le-volet-du-controle}

插入控件时（或通过右键 › 编辑），右侧窗格可设置：

- 控件的**名称**，供脚本使用（留空则自动命名）；
- 控件的**标签**；
- **链接的单元格**：该字段获得焦点时，单击工作表即可填入；
- **操作**：库中某个脚本的函数（脚本选项卡）。

控件可以先不设操作，稍后再链接。操作所做的全部修改只需一次 `Ctrl+Z` 即可撤消。

## 操作控件 {#manipuler-un-controle}

拖动可移动控件；`Ctrl+单击` 选中控件以调整大小；右键：运行、编辑、剪切、复制、删除。

## 在脚本中 {#dans-un-script}

脚本通过 `controls.list`、`controls.get` 和 `controls.on` 读取和监听控件：请参阅 [Lua 脚本](lua)。
