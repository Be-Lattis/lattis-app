# 入门

Lattis 的使用方式与电子表格相同：无限延伸的网格、顶部的功能区、底部的工作表选项卡。不同之处在于底层：您键入的每个表格都会成为一个真正的数据库表，带有类型，并且可以用 SQL 查询。

## 导览 {#visite-guidee}

导览用三分钟在一个新的小工作簿上展示要点：输入的表格、计算列、用 REFERENCE 关联的两个表格、数据透视表及其图表，以及一条 SQL 查询。您可以亲自完成每一步，也可以点击“下一步”由 Lattis 代为完成；“跳过”（或 `Esc`）结束导览。首次启动时会提供导览，也可从帮助重新开始（? › 导览）。

## 自动识别的表格 {#tableaux-detectes}

在任意位置键入一行标题，然后键入几行值：Lattis 会将其转换为**表格**，每列有一个类型，表格有一个名称（第一个表格采用选项卡的名称，可在编辑栏左侧更改）。紧挨着表格键入的行或列会扩展该表格；粘贴的数据块也会成为表格。如果第一行包含数字或日期，则它是数据：标题“列 1”“列 2”……会放在上方，可供重命名。`Ctrl+L` 可将区域套用表格格式。

不在表格中的内容仍是**自由单元格**：标题、参数、合计。所有操作都可以用 `Ctrl+Z` 撤消，包括创建表格。识别规则、事后键入的标题、两行标题分组、右键菜单：请参阅[表格](tableaux)。

## 列类型 {#types-de-colonnes}

每列都有一个类型，根据您键入的内容推测：文本、整数、小数、日期（带或不带时间）、布尔值，或计算列（整列使用一个公式）。可在列标题菜单中更改类型；请参阅[列类型](tableaux#types-de-colonnes)。

## 排序和筛选 {#trier-et-filtrer}

标题的 ▾ 可对表格排序（从 A 到 Z、从 Z 到 A、自定义顺序），并按值或按条件筛选该列。排序会永久改变行的顺序；空单元格排在最后。请参阅[排序和筛选](tableaux#trier-et-filtrer)。

## 键 {#cles}

**键**是值唯一且全部已填写的列（客户代码）：它标识每一行，显示在边距中，并用于 [REFERENCE](fonction:REFERENCE) 查找。名为 ID 或值为 1、2、3…… 的第一列会自动成为键，添加的行会获得下一个编号。请参阅[键](tableaux#cles)。

## 公式 {#formules}

公式以 `=` 开头，并通过列名引用列。在表格列中键入的公式会应用于整列：

```
=[Quantity]*[Unit price]
```

有关引用和函数列表，请参阅[公式](formules)。键入时，按 `F1` 可打开光标所在函数的帮助页面。

## 合并选项卡 {#regrouper-des-onglets}

每月、每年或每个城市一个选项卡，且列相同？数据 › 合并选项卡…会将它们合并为一个带有类别列的表格，并更新引用它们的公式。请参阅[合并选项卡](regroupement)。

## 选择选项卡（一次一年、一个月、一个城市） {#onglet-a-choix-une-annee-un-mois-une-ville-a-la-fois}

右键单击选项卡 › **选择依据** › 某一列（Year）：选项卡一次只显示一个值，从其 ▾ 列表中选择，就像每年一个选项卡一样；**新年份…**可添加一个值。请参阅[选择选项卡](regroupement#onglet-a-choix-une-annee-un-mois-une-ville-a-la-fois)。

## 保存 {#enregistrer}

工作簿是单个 `.lattis` 文件。`Ctrl+S` 保存；崩溃后，下次启动时会提示恢复修改。在关闭工作簿之前，`Ctrl+Z` 始终可用，即使在 `Ctrl+S` 之后也是如此，但历史记录不会保存在文件中。文件 › 导入和导出可读写 CSV、`.xlsx` 和 `.ods`。请参阅[文件和恢复](fichiers)和[页面布局和打印](impression)。

## 保护工作表或工作簿 {#proteger-une-feuille-ou-le-classeur}

审阅 › 保护工作表、保护结构（只允许在表格中输入）和保护工作簿可防止**意外修改**，可设置可选的密码（请参阅[保护](cellules#proteger)）。这不是安全措施：文件并未加密，掌握合适工具的人可以读取其数据或在没有密码的情况下取消保护。请勿依赖它来保护机密数据。
