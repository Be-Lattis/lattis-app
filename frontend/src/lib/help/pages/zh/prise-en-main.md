# 入门

Lattis 的使用方式与电子表格相同：无限延伸的网格、顶部的功能区、底部的工作表选项卡。不同之处在于底层：您键入的每个表格都会成为一个真正的数据库表，带有类型，并且可以用 SQL 查询。

## 自动识别的表格 {#tableaux-detectes}

在工作表的任意位置键入几行：一行标题，然后是值。Lattis 会识别出这个数据块并将其转换为**表格**：标题突出显示，每列获得一个类型，表格获得一个名称，您可以在编辑栏左侧的表格名称框中更改它（键入新名称，然后按 Enter）。工作表上的第一个表格采用选项卡的名称（去掉空格：“Sales 2026”变为 `Sales2026`），之后的表格依次为 Table1、Table2…… 重命名选项卡时，也会重命名使用该名称的表格（反之则不会）；该表格不显示名称标记，因为选项卡已经显示了名称。

- 至少需要两列两行（2 × 2 方块中有三个已填写的单元格）：单列列表或单独一行仍保持为自由单元格。
- 您键入的第一行就是标题，即使它与后续各行相似（“Name | City”之后是“Lea | Paris”），除非其中包含非文本的值：数字、日期、时间、布尔值、百分比、金额（“Lea | 31”、“Country | 2024”、“10 | 20”）。此时所有键入的行都是数据，标题会放在它们的正上方，名称为灰色斜体的“列 1”“列 2”……：在此键入每列的名称，或右键单击第 1 行 ›“将第一行用作标题”（也位于右键 › 表格中）：该行会成为标题并取而代之，“列 n”所在的行消失，公式随之更新；如果某列唯一的文本就是该名称，则该列恢复为数字类型。若要以数字作为列名，请在其前面键入撇号（'2024）。如果上方没有空位（工作表的第一行、正上方的单元格、标题或表格），这些单元格保持为自由单元格：开始 › 套用表格格式（`Ctrl+L`）可将其转换为表格，以其第一行作为标题。
- 在表格正下方键入的行会扩展该表格；在其紧右侧键入的列也是如此。
- 从 Excel 或其他程序粘贴的数据块会成为表格，标题规则与键入时相同：如果第 1 行只包含文本，它就是标题；若含有数字、日期等（“Country | 2024”、“10 | 20”），则该行为数据，上方使用“列 1”“列 2”……作为标题（右键单击 ›“将第一行用作标题”可将其改回标题）。如果粘贴在工作表的第一行、上方没有空位，“列 n”标题会占据粘贴的第 1 行的位置，整个数据块下移一行。
- 在数据之后键入标题：在表格正上方的行中键入名称。一旦在看起来像数据的标题（“Lea | 31”、“列 1”）上方有两个名称，状态栏就会提示“用作标题”；否则，请右键单击其中一个单元格 ›“用作“Table1”的标题”（或右键单击标题 › 表格 ›“将上方的行用作标题”）。这些名称会替换列名（留空的单元格保留原有列名），旧标题成为第 1 个数据行（如果原来是数字，则仍为数字），公式随之更新；`Ctrl+Z` 可撤消。在上方只键入一个词时，它仍保持为标题文字。
- 将一个表格拖到另一个表格旁边可将它们合并。
- 在表格的单元格上按 `Del`：如果某行不再含有任何键入的内容，该行会被删除，就像从未键入过一样（计算列、选择选项卡的隐藏列或整数键自动给出的编号都不会使其保留；状态栏显示“已删除 N 个空行”，`Ctrl+Z` 可将其恢复）。原本就为空、`Del` 未清除任何内容的行会保留。
- 不属于表格的内容仍是**自由单元格**，与 Excel 相同：标题、参数、合计。

所有操作都可以用 `Ctrl+Z` 撤消，包括创建表格。

在表格中**右键单击**时，首先显示只适用于此处的命令（转到、将第一行用作标题、在最后一行上将此行移出表格、在标题上将上方的行用作标题……），然后是剪切、复制、粘贴；清除内容、设置单元格格式…（`Ctrl+1`）、条件格式…；备注。最后是每个对象的子菜单，以其名称作为标题：**排序和筛选**、**行“12”**（表格有键时显示其键：在上方或下方插入、删除行）、**列“Name”**（重命名、类型和键、数据验证、筛选选项卡、转换为值、在左侧或右侧插入、删除列）和**表格“Readings”**（标题、共享、转换为区域、删除表格）。行号、列字母、数据透视表（**数据透视表“Sales”**）、图表和按钮遵循相同的顺序。

### 标题分组（上方的行） {#groupes-d-en-tetes-ligne-du-dessus}

如果标题上方有一行分组（WOODLAND 位于 Name、Status 和 Plot 上方），请右键单击标题 › 表格 ›“两行标题（上方为分组）”：这些单元格（无论是否合并）会成为表格的分组，像 Excel 一样显示在标题上方。此时列名为“分组.名称”：在公式中为 `Inventory[WOODLAND.Name]`，在 SQL 中为 `"WOODLAND.Name"`。在分组栏中键入可命名或重命名分组（公式随之更新），清除则删除分组。“删除标题分组”会将完整名称恢复到单独一行。

没有分组的列保持为**单层**：其在分组栏中的单元格与其标题构成一个跨两行合并的单元格，其名称中没有点号。Lattis 会自动调整：如果分组只覆盖一列，而该列的标题没有真正的名称（“列 17”上方的 Topography），则分组会成为该列的名称；与标题重复的分组（Discoverer 上方的 DISCOVERER）会消失。若要手动调整，请使用开始 › 合并后居中：

- **某列的分组栏单元格和标题** › 合并：该列变为单层；它保留其子标题，如果其标题是自动生成的，则采用分组的名称；
- **单层的列** › 取消合并（同一按钮）：分组栏单元格与标题分开；在其中键入分组名称（如果不键入任何内容，则仍保持单层）。在标题中键入“分组.名称”效果相同；
- **多个相邻的分组栏单元格** › 合并：这些列上方形成一个分组，采用它们原有的第一个分组（如果没有，则为“分组”：请在分组栏中键入其名称）；
- **覆盖多列的分组** › 取消合并：分组保留在其第一列上，其他列变为单层。

每次操作都会重命名列（公式和 SQL 随之更新），作为一个撤消步骤，并在状态栏中说明所做的更改。不能将分组栏与数据、表格外的单元格或另一个表格合并。

## 列类型 {#types-de-colonnes}

每列都有一个类型，根据您键入的内容推断：

| 类型 | 示例 |
| --- | --- |
| 文本 | Paris、Ref-001 |
| 整数 | 12、-3 |
| 小数 | 12.5；$1,234.50 |
| 日期 | 2026/1/15 |
| 真/假 | TRUE、FALSE |
| 计算 | 应用于整列的公式 |

不再符合类型的值会在可能时扩展列的类型（在整数列中键入小数会将其变为小数列，状态栏会给出提示）；否则该单元格会被标记为错误。类型可在列标题菜单中更改。

## 排序和筛选 {#trier-et-filtrer}

列标题的 ▾（或右键，或数据 › 排序和筛选）可按该列对表格排序：从 A 到 Z、从 Z 到 A，或按**自定义顺序**。排序会永久改变行的顺序；空单元格始终排在最后。同一菜单还可以按值（列表末尾为“(空白)”）或按条件筛选该列。

### 自定义排序 {#tri-personnalise}

**自定义排序…**打开该列的值列表，可按您需要的顺序排列，类似于 Excel 的自定义序列：拖动这些值，使用上移、下移、移至顶部、移至底部按钮，或使用键盘 `Alt+↑` / `Alt+↓`（`Alt+Home` / `Alt+End`）。选择**按此顺序**或**倒序**，然后单击确定。比较值时不区分大小写；不在顺序中的值按升序排在后面，空白值保持在最后。

- **内置序列**：星期（星期一……星期日）、短星期、月份（一月……十二月）、短月份。当列中的值与某个序列匹配时，会直接提供该序列。
- **工作簿序列**：勾选“将此顺序保存为自定义序列”并为其命名（尺码、优先级……）；之后它可用于任何其他列或数据透视表字段，并随文件一起保存。
- 该顺序**为该列保留**：下次自定义排序时会再次使用；由查询加载的表格在每次刷新时都会按此顺序重新排序（只要没有被普通排序取代）。顺序中有而数据中缺失的值会保留在顺序中，以备将来出现。
- `Ctrl+Z` 一步撤消排序。在脚本中：`tables.sort_custom`、`tables.sort_lists`、`tables.set_sort_lists`、`columns.sort_order`。

## 键 {#cles}

**键**是值唯一且全部已填写的列：客户代码、产品编号。它标识每一行，显示在边距中以代替行号，并用于 [REFERENCE](fonction:REFERENCE) 查找。

创建表格（键入、粘贴、套用表格格式）时，如果第一列只包含唯一且全部已填写的整数，并且其标题为 **ID**，或其值为按顺序排列的 **1、2、3……**，则该列会自动成为键。状态栏会给出提示（“已将键设置为 ID”），标题中会显示 🔑；`Ctrl+Z` 会连同创建一起撤消，右键 › 删除键则只删除键。导入的文件会原样保留其表格。

在其他情况下，如果表格的第一列适合作为键，Lattis 会低调地给出建议，只需单击一次即可。“不再建议”会取消对该表格的建议，该表格将保留行号。

**自动编号。** 向键为整数的表格添加行时，新行会获得下一个编号（最大值加 1），无论该行是在表格下方键入、粘贴、在中间插入还是由脚本添加的；其他行不会重新编号。不是键但遵循规则序列的第一列（10、20、30……）在末尾添加行时也会自动填写。您在该列中键入的值会替换建议的编号。标题的工具提示会指明编号列。

在没有键的表格中键入查找公式（[REFERENCE](fonction:REFERENCE)、VLOOKUP、XLOOKUP、EXISTS……）时，Lattis 会询问应使用什么：

- 表格的**行号**：第一行为 1，按表格中的顺序，排序或插入行时会变化。VLOOKUP 会变为 `INDEX(…, MATCH(…, 0))`：返回找到的第一行，允许重复。该选择适用于整个表格：不会再次询问；
- **被查找的列**，它会成为表格的键：其值必须唯一且全部已填写，之后该列中的重复值会被拒绝。

`Ctrl+Z` 会同时撤消公式和此选择。已有键的表格不会询问，粘贴或导入的公式会保留行号而不询问。

## 合并选项卡 {#regrouper-des-onglets}

许多工作簿都有**每月、每年或每个城市一个选项卡**，各选项卡的列相同。Lattis 会识别出它们：这些选项卡下方带有相同颜色的线条，系列之后有一个“⧉ 12 个相似的选项卡”标记（悬停时会突出显示相关选项卡）。在导入 Excel 工作簿后、打开时，或者当您第三次复制系列中的某个选项卡时（甚至在重命名副本之前），状态栏会提示一次：**合并…**、**稍后**（标记保留）或**不再建议**（保存在文件中：收到该文件的同事不会再被询问；右键单击标记也可找到）。

如果各选项卡之间至少有三分之二的列相同，这些选项卡就会被归为一组：年中添加的列在缺失的地方保持为空，重命名的列（“Amount $”）会与相邻的列（“Amount”）配对，窗格中始终会显示这一配对。系列中的选项卡名称可被识别：月份、年份、季度、周、日期、数字或字母序列（“Lot 1”、“Lot 2”；“Appendix A”、“Appendix B”）、市镇。

**数据 › 合并选项卡…**（或右键单击所选的多个选项卡）打开窗格：

1. **选项卡**：要合并的表格，可勾选，按选项卡顺序排列；
2. **类别列**：其名称（根据选项卡名称预填：Month、Year、Quarter、City、共同部分如“Lot”，否则为 Category，始终可以编辑）、类型，以及从每个选项卡获取的值（如有需要可更正）。该列位于表格的第一列，并带有包含其值的下拉列表；
3. **列**：匹配情况（✓ 存在，∅ 缺失，“Amount $ → Amount”已配对）和最终类型；变为文本的列会被标出；
4. **之后**：表格和新工作表的名称，以及旧选项卡的处理方式：**删除**（默认）或**保留并隐藏**，其表格重命名为 `January_old`；
5. **预览**：前几行和总行数，然后是引用旧选项卡的公式的摘要：“已迁移 14 个公式，2 个需要手动修正”，并附有列表（工作表、单元格、公式更改前 → 更改后）。

**合并**一步完成所有操作：`Ctrl+Z` 可恢复原来的选项卡。格式和错误的输入会跟随其所在的行。如果各选项卡之间没有重复的值，则保留**键**；否则合并后的表格没有键（值保持不变），Lattis 会举例说明：“没有键：F-001 同时出现在 January 和 February 中”。

引用旧表格的内容会被**迁移**到合并后的表格，并限定为旧选项卡对应的月份（年份、城市），在同一撤消步骤中完成，且值保持不变。如果“Summary”工作表中原来有 `SUM(January[Amount])`、`SUM(February[Amount])`……，迁移方式如下：

| 之前 | 之后 |
|---|---|
| `SUM(January[Amount])` | `SUMIFS(Sales[Amount], Sales[Month], "=January")` |
| 某列（或基于各列的计算，`SUM(January[Price]*January[Qty])`）的 `AVERAGE`、`MAX`、`MIN` | `AVERAGEIFS`、`MAXIFS`、`MINIFS`、`SUMIFS` |
| `COUNTA(January[Customer])` | `COUNTIFS(Sales[Customer], "<>", Sales[Month], "=January")` |
| `SUMIF`、`COUNTIF`、`SUMIFS`…… | 相同的函数，改为 `…IFS` 形式，并添加月份条件 |
| `ROWS(January)` | `COUNTIFS(Sales[Month], "=January")` |
| `COUNT`、`MEDIAN`、`MAX` 或 `AVERAGE` 中的多列、`UNIQUE(January[Customer])`…… | 筛选后的列：`FILTER(Sales[X], Sales[Month]="January")` |
| 基于 January 的数据透视表 | 基于 Sales 的相同数据透视表，并带有报表筛选 Month = January |
| 基于 January 的图表 | 基于 Sales 的相同图表，并带有筛选 Month = January（显示在其窗格中，可删除） |

其他表格的计算列和条件格式规则遵循相同的规则。以下情况**需要手动修正**，并会注明原因：具体某一行（`January[Amount][3]`）、`REFERENCE`、`VLOOKUP` 和 `EXISTS`（它们在指定名称的表格中查找键）、`SUBTOTAL`、整个表格（`FILTER(January, …)`）、来自旧表格的检查列表、查询；SQL 文本和 Lua 脚本不会被检测。在这种情况下，旧选项卡默认保留并隐藏，以便这些公式继续工作；否则会被删除。如果没有类别列，就无法再区分各选项卡：所有内容都需要手动修正。之后，按月汇总最好使用 Month × Amount 数据透视表，它会自动跟随新行。

在受保护的工作表上、已筛选的表格上（请先删除筛选）、由查询加载的表格或在服务器上共享的表格上，不能进行合并。

### 包含多个表格的选项卡 {#onglets-a-plusieurs-tableaux}

“2025”选项卡通常包含多个表格：每年都会变化的销售和支出表，以及从一个选项卡原样复制到下一个选项卡的价目表。此时 Lattis 会合并**整个工作表**：它将各选项卡中的表格逐个按族（列相同，如上所述）配对，并在窗格的**选项卡上的其他表格**下说明每个表格的处理方式：

- **合并**（会变化的表格：销售、每月备注）：生成带有类别列的合并表格，**跟随**选择选项卡；
- **只保留一份**（当各处数据相同时提供：价目表）：保留最后一个选项卡中的表格，不带类别列，所有年份共用。如果某份副本有所不同（“Prices 在 2024 年有变化”），窗格会将其标出，并建议改为合并，以免丢失任何内容；
- **留在原选项卡上**（适用于只出现在一个选项卡中的表格）：此时该选项卡会被保留并可见，以橙色选项卡显示以便查找，窗格中会给出说明。

合并后的工作表采用**最近一个选项卡的布局**：每个合并后的表格占据其原表格的位置，下方的内容按其增长的幅度下移，该选项卡中没有的表格依次放在下方。各选项卡的**自由单元格**会被迁移（可在窗格中取消勾选）：各处完全相同的标题、标签或合计只保留一份；表格下方的 `=SUM(Sales2025[Amount])` 变为 `=SUM(Sales[Amount])`，给出所显示年份的合计；在各选项卡之间不同的值（2024 年为“Target: 5,000”，2025 年为“6,000”，标题“January 2025”）会成为**按年单元格**：它显示所选年份的值，您在其中键入的内容只适用于该年份（选择“(所有年份)”时为空）。

类别也可以来自某个**单元格**，而不是选项卡名称（当选项卡名为 Sheet1、Sheet2……时，每个选项卡的 A1 中有标题“January 2025”）：窗格会建议最可靠的来源，可在**取自**中选择。在**同一工作表上以标题分隔堆叠**的相似表格（“Paris”、“Lyon”、“Marseille”）也以同样方式合并，类别取自这些标题。如果每个选项卡都有一个 **Date** 列，且其值都在该选项卡的月份内，则 Month 列就没有必要了：“不添加列”复选框默认处于勾选状态（按日期筛选就足够了）；如果仍要添加该列，请取消勾选。

**跟随年份**：在带有选择选项卡的工作表上，跟随年份的表格会在其边框角上显示一个小**标记**，标明所显示的年份；没有标记的表格对所有年份都相同。右键单击表格 › 表格 › **跟随年份**（或单击标记）可勾选或取消勾选：勾选时会在最后添加 Year 列，并填入所显示的年份（选择某一年份时隐藏）；取消勾选时，如果该列只有一个年份则将其删除，否则保留该列（不会丢失任何内容），表格显示其所有行。在设置为某一年份的工作表上设置格式的表格（插入 › 表格）会自动跟随该年份；状态栏会给出提示。`Ctrl+Z` 可撤消。脚本：`tables.follow_choice("Prices", false)`。

## 公式 {#formules}

公式以 `=` 开头，并通过列名引用列。在表格列中键入的公式会应用于整列：

```
=[Quantity]*[Unit price]
```

有关引用和函数列表，请参阅[公式](formules)。键入时，按 `F1` 可打开光标所在函数的帮助页面。

## 选择选项卡（一次一年、一个月、一个城市） {#onglet-a-choix-une-annee-un-mois-une-ville-a-la-fois}

与其每年一个选项卡，不如只保留一个带有 Year 列的表格，并将其工作表设置为**选择选项卡**：右键单击选项卡 › **选择依据** › 该列（Lattis 会建议不同值较少的列）。选项卡变为“Sales · Year ▾”；其小箭头（或在选项卡上按 `Alt+↓`）会展开值列表：

- **某个值**（2025）：工作表上所有具有该名称列的表格只显示该值对应的行，而各处相同的 Year 列会被隐藏。没有该列的表格（价目表）不变。工作表上的数据透视表只统计该年份，就像强制应用了报表筛选一样；`SUBTOTAL`、图表和查找也会像跟随筛选一样跟随它；
- **(所有年份)**：不再隐藏任何内容，该列重新出现；
- **新年份…**会建议下一个值（2025 之后为 2026，November 之后为 December，Lot 3 之后为 Lot 4），将其添加到该列的下拉列表中并显示它：工作表看起来是空的，可以开始填写，就像一个新选项卡一样。`Ctrl+Z` 可撤消。

**从列开始**：对于已填好数据的表格，右键单击 Year 列标题（或其 ▾ 菜单） › **按此列筛选选项卡**可达到同样的效果，而无需通过选项卡或合并选项卡。选项卡开始时显示所有值：使用其 ▾ 箭头选择年份。对于计算列、空列或不同值超过 100 个的列，该菜单项显示为灰色，并有工具提示说明原因；对于已用作选择依据的列，该菜单项变为**停止筛选选项卡**。`Ctrl+Z` 可撤消。

**按公式**：如果要选择的值不是某一列，而是根据每行的各列计算得出，请右键单击选项卡 › **选择依据** › **公式…**：`=YEAR([Date])` 无需 Year 列即可按年份分选项卡，`=TEXT([Date],"mmmm")` 按月份，`=IF([Amount]>1000,"Large","Small")` 按区间。键入时，对话框会提示函数和列，推测类别名称（Year、Month……，可编辑），并显示公式的前几个值以及将跟随它的工作表上的表格：即具有公式所引用的所有列的表格（其他表格不变；右键 › 表格 › **跟随**可将其移除或重新加入）。选项卡的列表按自然顺序对值排序（2024 在 2025 之前，January 在 February 之前）。由于没有需要填写的列，因此没有“新年份…”：在表格下方键入的行不会自动获得任何值，但在您键入时它会保持显示，直到选项卡的值下次更改，此时它会归入其公式给出的值。`=SHEETCHOICE()` 返回所选的值（对于 `=YEAR(…)` 为数字）；工作表上基于具有该公式各列的表格所建的数据透视表只统计所选的值。重命名被引用的列时，公式会随之更新。脚本：`sheets.choose_by_formula("Sales", "=YEAR([Date])", "Year")`。

**从数据透视表开始**：在数据透视表窗格中右键单击行、列或筛选中的字段（或网格中该字段的 ▾） › **按此字段筛选选项卡**。选择选项卡设置在数据透视表所在的工作表上，依据其源表格中的列：数据透视表只统计所选的值，工作表上基于具有该列的表格所建的其他数据透视表以及具有该列的表格也是如此。如果源表格位于另一个工作表上，则不会被筛选；其值用于填充选项卡的列表。对于基于由查询加载的表格所建的数据透视表，此功能同样适用。

在表格下方或在其他年份各行的灰色条带中键入的行会自动获得所显示的年份；粘贴或插入的行也是如此。选择并不是筛选：“清除筛选”不会影响它，而您通过 ▾ 设置的筛选会叠加在其上。`Ctrl+Alt+PgDn` 和 `Ctrl+Alt+PgUp` 转到下一个或上一个年份；状态栏会提示“Year: 2025（选项卡选择）”。

**工作表上**的自由公式看到的是经过筛选的表格：放在表格下方的 `=SUM(Sales[Amount])` 给出所显示年份的合计，就像原来的“2025”选项卡一样。其他工作表上的公式、SQL 选项卡和脚本看到的是所有行。`=SHEETCHOICE()` 返回所选的值，可用于跟随选项卡的汇总：`=SUMIFS(Sales[Amount], Sales[Year], SHEETCHOICE())`。

更改年份属于导航，就像切换选项卡一样：它不是一个撤消步骤，但最后选择的值会保存在文件中，并在打开时恢复（如果该值已没有任何行，选项卡会显示最后一个值，除非刚刚使用了“新年份…”）。重命名该列会重命名类别：选项卡随之更新。右键 › 选择依据 › “停止按…选择”会删除选择（可撤消）。在共享工作簿中，选择只保留在您的计算机上：不会发送给其他人。

脚本：`sheets.choice()`、`sheets.set_choice("Sales", 2025)`、`sheets.choose_by("Sales", "Year")`（对于放在其他位置的数据透视表所在的工作表：`sheets.choose_by{table = "Sales", column = "Year", sheet = "Summary"}`）、`sheets.new_choice("Sales", 2026)`（请参阅 [Lua](lua)）。

## 保存 {#enregistrer}

工作簿是单个 `.lattis` 文件（一个 SQLite 数据库及其说明）。`Ctrl+S` 保存。关闭含有未保存修改的工作簿或 Lattis 窗口时，会先询问是否保存；如果 Lattis 在未保存的情况下停止（崩溃、强制关闭），下次启动时会提示恢复这些修改（请参阅[文件和恢复](fichiers)）。

撤消历史从不保存在文件中：在关闭工作簿之前，`Ctrl+Z` 始终可用，即使在 `Ctrl+S` 之后也是如此；但重新打开的文件（或发送给他人的文件）不再有任何历史记录，也不包含已删除的列或行。

从共享文件夹（网络、OneDrive 等）打开的工作簿会通过放在其旁边的隐藏小文件 `~$name.lattis` 通知其他计算机：其他计算机打开该工作簿时会收到警告，并可以以只读方式打开。如果文件在打开后已在别处被修改，`Ctrl+S` 会提示保存副本、覆盖或取消。

文件 › 导入可读取 CSV 和 Excel 文件；文件 › 导出可写入 CSV、`.xlsx` 或 OpenDocument（`.ods`）（在用于 Excel 的 CSV 中，以 `=`、`+`、`-` 或 `@` 开头的文本前面会加上一个撇号，以免 Excel 将其作为公式执行）；文件 › 打印 / PDF 按照视图 › 页面布局中的设置进行打印或另存为 PDF（请参阅[页面布局和打印](impression)）。

## 保护工作表或工作簿 {#proteger-une-feuille-ou-le-classeur}

审阅 › 保护工作表禁止对工作表内容进行任何修改；保护结构只允许在表格中输入（值、添加或删除行、排序、筛选）；保护工作簿禁止添加、删除或重命名工作表，还可以锁定所有工作表的结构或内容。可选的密码可防止误取消保护。与 Excel 一样，这是防止**意外修改**的保护措施，而不是安全措施：文件并未加密，掌握合适工具的人可以读取其数据或在没有密码的情况下取消保护。请勿依赖它来保护机密数据。
