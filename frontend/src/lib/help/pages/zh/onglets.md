# 文档和网页

除了工作表，工作簿还可以包含**文档**，用于撰写报告。在底部标签的“+”上或在某个标签上单击右键即可添加（插入）。

## 文档 {#document}

一张无限延伸的富文本页面：标题、列表、引用、代码、对齐、字体、颜色、链接和图片，像在文字处理软件中一样通过功能区设置格式。

还可以在其中插入由工作簿表格驱动的动态元素：

- **图表**和**数据透视表**（与工作表上相同的窗格）；
- 运行某个脚本函数的**按钮**；
- 值写入单元格的**字段**（复选框、列表、输入框等）。

右键单击已插入的元素：显示与工作表上相同的菜单；在其他位置右键：显示插入菜单。最后一次按键片刻之后，文本会自动保存，作为工作簿的一个撤消步骤。文件 › 打印 / PDF 作用于该文档。

## 网页 {#page-web}

网页（标签中的 HTML、CSS 和 JavaScript）已禁用：其 JavaScript 可能把工作簿中的数据泄露出去。现有工作簿中的网页标签会保留，但不显示；您可以删除它。您的组织可以在桌面应用中重新启用网页，浏览器版中始终禁用。
