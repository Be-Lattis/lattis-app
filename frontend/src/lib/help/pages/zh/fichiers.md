# 文件和恢复

Lattis 工作簿是单个 `.lattis` 文件：一个 ZIP 压缩包，其中包含一个经过压缩的 SQLite 数据库和一个简短的清单文件。它可以像 Excel 工作簿一样通过电子邮件发送和归档；用 7-Zip 或 WinRAR 解压后（Windows 文件资源管理器无法读取其压缩格式 Zstandard），任何 SQLite 工具都可以读取其中的表格。

## 保存 {#enregistrer}

`Ctrl+S` 保存，`F12` 或 `Ctrl+Shift+S` 以其他名称保存。保存过程是安全的：文件先写入到旧文件旁边，经回读校验后再替换旧文件；保存期间如果突然关机，旧文件仍完好无损。

- 未更改的工作簿不会被重写。
- 对于较大的工作簿，状态栏会显示保存进度。
- 如果磁盘空间不足，Lattis 会在写入任何内容之前给出提示（“需要…，剩余…”）。
- 撤消历史以及已删除的列和行永远不会写入文件。

关闭含有未保存修改的工作簿或窗口时，会先询问是否保存。

## 版本历史记录 {#historique-des-versions}

每次保存都会在文件旁（隐藏文件夹 `.lattis-versions`）保留工作簿的一个版本：每 10 分钟一个，最多 20 个，总大小不超过工作簿的 10 倍。文件 › 版本历史记录列出这些版本（日期、作者、大小）；**保存版本** 以名称保留一个版本，该版本不会被删除。**打开** 以只读方式显示版本；**还原** 用它替换工作簿，之前的版本保留在列表中。在 Lattis Server 上共享的工作簿没有历史记录。

## 意外事件后的恢复 {#recuperation-apres-un-incident}

在您工作时，Lattis 会在您的计算机上保留一份工作簿的工作副本。如果 Lattis 在未保存的情况下停止（崩溃、强制关闭、断电），下次启动时会提示恢复修改：恢复会按工作簿当时的状态重新打开它，并保留其撤消历史；放弃则回到已保存的文件。

您的输入和命令一经执行就会写入磁盘：即使断电也不会丢失。

## 在网络上共享的工作簿 {#classeur-partage-sur-le-reseau}

从共享文件夹打开的工作簿会通过一个隐藏的小文件 `~$name.lattis` 通知其他计算机。其他计算机打开该工作簿时会收到警告，并可以以只读方式打开。如果文件在打开后已在别处被修改，`Ctrl+S` 会提示保存副本、覆盖或取消。

## 向实时共享的工作簿添加表格 {#ajouter-un-tableau-a-un-classeur-partage-en-direct}

在协作工作簿（在 Lattis 服务器上实时共享）中，所有者或设计者在发布后新建的表格（输入、粘贴、插入、由区域转换等）一经创建就会自动添加到共享工作簿；离线时在重新连接后添加。仍只留在您计算机上的表格（由查询加载、被服务器拒绝或由编辑者创建）会在其边框上方显示琥珀色的**仅本机**标签：其他成员看不到它。单击该标签，或右键单击表格 › **添加到共享工作簿…**，会在服务器上的工作簿中创建该表格及其所有行：其他成员会立即收到（位于工作表上的相同位置；如果他们那边该位置已被占用，则放在下方），状态栏中会显示一条消息，之后它会像其他共享表格一样同步（输入、冲突、权限）。**共享到 Lattis 数据湖…**（排在第一项的“将此表格添加到共享工作簿”）以及**管理访问权限** › 角色和权限中的表格列表下方也提供相同的操作。

- 仅限工作簿的所有者和设计者，且必须在线：否则对话框会给出提示。
- 列的类型与其他共享表格一样被固定；计算列在每台计算机上仍然各自计算。必须先修正无效的输入。
- 服务器拒绝（例如名称已被工作簿中的另一个表格使用）时，状态栏会显示原因，且不做任何更改。
- 添加操作不能用 `Ctrl+Z` 撤消（确认对话框会提醒您）：若要从共享工作簿中移除该表格，**删除表格**会为所有人删除它。撤消（`Ctrl+Z`）表格本身的创建也会将其从服务器上删除（对所有人生效）；`Ctrl+Y` 会重新创建并再次添加它。

## 管理共享工作簿的访问权限 {#gerer-l-acces-a-un-classeur-partage}

**文件 › 管理访问权限…**（或帐户菜单）用于设置谁可以查看和修改发布在 Lattis 服务器上的工作簿。每个成员拥有一个或多个**角色**；其权限为所有角色权限的合集。

- **成员**：邀请某个地址并指定其角色（对话框会说明这些角色允许的操作），单击角色标签上的 ✕ 可移除角色，单击 **+ 角色**可添加角色。每个人下方有一行文字说明其可以执行的操作（“查看、添加、编辑自己的行”）。通过团队获得的角色以虚线显示，需在**团队**中更改。最后一位所有者受到保护：请先将该角色授予其他人。
- **角色和权限**：一个表格显示每个角色是否可以**查看**、**添加行**、**编辑自己的行**（自己添加的行，包括删除）、**编辑所有行**以及更改**结构和权限**（✓ 是，◐ 部分：部分行或部分表格，– 否）。选择一个角色，即可设置其对工作簿、每个工作表和每个表格的访问权限：*无访问权限*、*查看*、*查看、添加、编辑自己的行*或*查看和编辑全部*；“与工作表相同”或“与工作簿相同”沿用上一级的访问权限。每个表格下方的筛选条件以句子形式显示（“只能看到 Region = “North” 的行”、“只能编辑 Salesperson = 当前登录用户的行”）；**限制…**或**编辑**用于设置筛选条件。所有者拥有全部权限；设计者也一样，但不能管理权限。
- **高级规则**（所有者）：规则会撤销某个表格上的某项权限，无论角色的访问权限如何，并以一句话表述（“除所有者和设计者外，任何人都不能删除“Sales”中的行。”）。可以从预设开始——**禁止删除**、**仅添加**、**仅编辑特定状态的行…**、**编辑自己的行但不能新建**（适用于可以添加和编辑自己的行的角色：此后只能编辑）——或者选择表格、角色、禁止的操作以及可能的例外。
- **以…身份查看**：从成员或角色所在的行，或在其选项卡中，显示该成员可以对某个表格执行的操作以及他能看到的行，这些信息以其身份从服务器上读取（包括规则）。
- **差异**：在 Lattis 之外（直接在 PostgreSQL 中）更改的规则；**重新编译权限**会恢复 Lattis 中的规则。

**从服务器移除…**（所有者；在此对话框底部，或在“文件”中）会为所有人从服务器删除工作簿：数据和权限、管道和表单；其 Data Lake 共享将被切断。各电脑上已有的副本会保留：其他成员会看到工作簿已被删除，并可保留自己的副本（**保存本地副本…**）。您的副本将作为本地工作簿保持打开。操作前会请求确认；此操作无法撤销。

## 服务器无法访问：离线工作或断开 {#serveur-injoignable-travailler-hors-ligne-ou-se-detacher}

当共享工作簿的服务器不再响应时（服务器已停止、网络中断），功能区下方会显示一个橙色横幅，例如“服务器 localhost:8080 没有响应”。**详细信息**显示技术错误（也会显示在工具提示和日志中）。

- **协作工作簿**：仍然可以编辑。输入、添加或删除的行、添加或重命名的列都会在您的计算机上等待（单元格角上显示灰色小三角，状态栏中显示“离线 — 3 项待发送”），即使关闭 Lattis 也不会丢失：它们与工作簿一起保存。服务器恢复后，它们会按您操作的顺序发送。在此期间被同事修改过的单元格会成为**冲突**（冲突窗格：保留您的值或对方的值）；服务器拒绝的内容（中断期间被撤销的权限、变为不可修改的列、被同事删除的行）会在您的计算机上被撤消，并显示一条消息。
- **冻结的工作簿**：在服务器恢复之前，仍然可以只读方式查看。

Lattis 会自动重试，间隔越来越长（从几秒到两分钟）；服务器一旦响应，横幅就会消失。横幅上的按钮：

- **重试**（也可通过文件 › **重试连接**）：立即尝试。
- **使用本地副本工作**：以您选择的名称将工作簿另存为普通工作簿，与服务器不再有关联，然后打开它。尚未发送的修改包含在副本中（消息中会说明）；这些修改在共享工作簿中也仍然处于待发送状态，共享工作簿本身不受影响。
- **从服务器断开…**（工作簿所有者；也可在文件中找到，在线或离线均可）：此工作簿成为普通的本地工作簿，不再同步。服务器上的工作簿不会被修改（其他成员仍然保留它，您也可以从服务器重新打开它）。从服务器打开的工作簿只是 Lattis 缓存中的一个副本：Lattis 会询问保存位置，然后删除缓存。断开操作无法撤消，确认对话框会提醒您这一点。

## 将表格共享到 Lattis 数据湖 {#partager-un-tableau-au-data-lake-lattis}

右键单击表格 › **共享到 Lattis 数据湖…**可让 Lattis 服务器上的其他工作簿读取该表格（插入 › Lattis 数据湖，SQL 选项卡），读取范围由受众决定：人员、团队，并可为每个受众设置行筛选。如果工作簿尚未发布，对话框会提供两种方式：

- **发布工作簿并管理权限**：将整个工作簿连同其角色和筛选条件发布到服务器（文件 › 发布到服务器…）；之后对话框会再次出现，以便共享该表格。
- **仅将此表格发布为数据源**：工作簿保留在您的计算机上，不对外提供。服务器保存该表格的一个副本，由一个以您的工作簿为数据源的管道提供数据。只发送**勾选的列**及其值（计算列发送其结果，而不是公式）；其他表格、工作表、公式、脚本和未勾选的列都不会离开本机。

数据源在您要求时更新：右键单击表格 › **更新数据湖数据源**，或在同一对话框中更新；勾选“每次保存工作簿时更新数据源”，即可在每次按 `Ctrl+S` 时发送。每次更新都会发送整个表格，并按所选模式写入：**全部替换**（数据集变为所发送的表格）、**追加**（行被添加到已接收的行之后）或**按键更新**（修改键相同的行，添加新行）。状态栏会显示摘要：读取、添加、修改、删除的行数，以及被服务器拒绝的值和其中第一个值的详情（行、列、原因）。您在工作簿中重命名、转换或删除的已发送列，在下次更新时也会在服务器上被重命名、转换或删除。与数据源的链接保存在工作簿中（请保存工作簿）；该对话框还可以更改名称、发送的列、模式、键和受众，**暂停**数据源（不再发送任何内容，数据集保留其最后的行），以及**移除数据源**（使用它的工作簿保留其最后一份副本）。“发布到服务器”和“管理访问权限”对话框会列出工作簿的数据源，并标记为“管道”。在插入 › Lattis 数据湖中，单独发布的数据集带有相同的标记，并注明来自哪个工作簿；未选择数据集时，“您推送的数据源”列表会显示您在服务器上的所有数据源，无论它们来自哪个工作簿。

您需要在服务器上拥有“数据发布者”角色，并且服务器需要接受由工作簿发送的数据源；否则对话框会给出提示。

## 将表格共享为表单 {#partager-un-tableau-comme-formulaire}

将活动单元格放在表格中，然后选择**插入 › 表单**：通过一个网页，无需打开工作簿即可从手机或计算机填写此表格。每次提交都会添加一行，成员可以实时看到新行；该行以表单的名义写入（“表单：<标题>”），填写人对工作簿没有任何权限。

表单由 Lattis 服务器提供：表格必须由工作簿的所有者或设计者在线发布在协作工作簿中。否则，对话框会说明缺少什么，并提供需要先执行的操作：**发布到服务器…**（本地工作簿）或**添加到共享工作簿…**（仅存在于您计算机上的表格），然后打开设计器。冻结的工作簿、由查询加载的表格、链接的数据湖数据集或推送的数据源不能创建表单。既不是所有者也不是设计者的成员可以复制向其开放的表单的链接。

设计器有三个选项卡，右侧是页面预览（手机或计算机宽度）；**在浏览器中打开预览**显示服务器上的真实页面，但不保存回答。

- **字段**：每列一个字段（“在表单中”复选框、用于移动的控点、标签、帮助、占位文本、必填、默认值：固定值或今天、现在、当前年份、填写人地址）。字段类型取决于列：文本或长文本、数字（可设上下限和单位）、日期、日期和时间、复选框或是 / 否，对于带有验证列表的列则为单选按钮或可搜索的列表。来自已发布表格中某列的列表由服务器重新读取；其他列表会被复制（“列表复制于…”，**更新**）。编号键由服务器设置；手动输入的键为必填项。当填写人点击“我的位置”时，**位置**字段会填写 Latitude 和 Longitude（或一个“lat, lon”列）。**由服务器设置的值**填写没有可见字段的列：接收时间、填写人、表单（其标题）、下一个编号或固定值；**添加“接收时间”列**会在表格中创建该列。使用选择选项卡时，类别可以是固定值、当前年份或一个字段。小标题将表单划分为多个部分。
- **外观**：标题、简介（粗体、斜体、链接、列表）、徽标和横幅、从易读调色板中选择的颜色、每页一个部分、按钮标签、感谢语、关闭消息、数据保护声明（附模板）、页面语言（法语或英语）。不支持上传照片或文件。
- **访问**：工作簿的成员（包括查看者）、选定的人员和团队，或在服务器上拥有帐户的任何人；所有人都使用其 Lattis 帐户登录。

底部以橙色显示检查结果（空列表、默认值不在列表中、列表的值对填写人可见等）。**保存草稿**保留表单但不开放；**开放表单**将其上线，并提供其链接、二维码（可保存为 PNG 或 SVG）以及**预填链接…**：每个值一个链接（例如每个站点一个二维码），打开时自动填写字段，并可选择“由链接锁定”，使这些字段不能修改。如果表格已有表单，对话框会先列出它们（复制链接、编辑…），并提供**新建表单…**。

## 导入 {#importer}

文件 › 导入可读取 CSV 文件（或分隔文本）、`.xlsx`、`.xlsm` 工作簿和 OpenDocument `.ods`：每个工作表成为一个选项卡，每个数据块成为一个表格，并保留格式、备注、验证列表和条件格式。当图表和数据透视表的数据是工作簿中的表格时，也会一并导入。导入结束时会报告未导入的内容（宏、其他对象）。

对于需要刷新的数据（JSON 或 Parquet 文件、SQLite 数据库、PostgreSQL、MySQL、SQL Server、网页），请改用查询：请参阅[导入数据和连接](connexions)。

## 导出 {#exporter}

- **CSV**：活动表格或整个工作表。在用于 Excel 的 CSV 中，以 `=`、`+`、`-` 或 `@` 开头的文本前面会加上一个撇号，以免 Excel 将其作为公式执行。
- **Excel（`.xlsx`）和 OpenDocument（`.ods`）**：整个工作簿。表格成为 Excel 表格，公式在目标格式中有对应写法时会被转换，否则按其值导出。数据透视表以值的形式导出；图表、条件格式、验证列表和备注在 `.xlsx` 中导出；脚本不会导出。报告会说明哪些内容未能原样导出。
- **PDF**：文件 › 打印，使用“Microsoft Print to PDF”打印机（请参阅[页面布局和打印](impression)）。

## 示例工作簿 {#classeur-d-exemple}

开始页面提供打开示例工作簿的选项：其中包含销售、客户、数据透视表、图表、地图、SQL 查询和脚本，以及一个介绍这些内容的“探索”选项卡。示例工作簿从不自动保存：若要保留，请使用文件 › 另存为。
